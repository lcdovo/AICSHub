# 满减活动与优惠券使用规则

## 一、促销活动概述

### 1.1 活动类型
本平台提供多种促销活动，包括满减、满折、优惠券、秒杀、团购等。消费者可根据需求选择参与，享受最大优惠。

### 1.2 活动原则
- 透明公开：活动规则清晰明确
- 先到先得：限量活动按提交顺序
- 公平公正：所有用户均可参与
- 真实有效：活动价格真实有效

## 二、满减活动

### 2.1 满减规则
#### 2.1.1 满减类型
- **阶梯满减**：满199减30，满399减80，满699减150
- **满件减**：买2件减50，买3件减100
- **满额赠**：满299元赠送指定商品
- **跨店满减**：参与活动的店铺订单合并计算

#### 2.1.2 满减计算
- 满减金额按商品实付金额计算（不含运费）
- 优惠券抵扣后的金额参与满减计算
- 满减在优惠券之后抵扣

### 2.2 满减使用条件
- 仅参与活动的商品可享受满减
- 满减可与优惠券叠加
- 满减不可与秒杀、团购等特殊活动叠加
- 满减金额不开发票

### 2.3 满减活动时间
- **日常满减**：长期有效
- **大促满减**：618、双11、双12等大促期间
- **节日满减**：春节、国庆、中秋等节日
- **会员日满减**：每月8日会员专属

## 三、优惠券

### 3.1 优惠券类型
#### 3.1.1 按优惠方式分类
| 类型 | 说明 | 示例 |
|------|------|------|
| 满减券 | 满X元减Y元 | 满200减30 |
| 折扣券 | 按比例打折 | 8折券 |
| 无门槛券 | 无使用门槛 | 10元无门槛 |
| 运费券 | 抵扣运费 | 免邮券 |
| 品类券 | 指定品类可用 | 耳机品类券 |

#### 3.1.2 按发放对象分类
- 新人券：新注册用户专属
- 会员券：不同等级会员专属
- 活动券：参与活动获得
- 补偿券：售后问题补偿
- 生日券：生日当月发放

### 3.2 优惠券获取
#### 3.2.1 领取方式
- **领券中心**：App首页-领券中心，每日限量领取
- **活动页面**：参与活动自动发放
- **会员中心**：会员等级专属优惠券
- **客服发放**：售后问题补偿券

#### 3.2.2 抢券技巧
- 关注领券中心更新时间（每日10:00）
- 开启优惠券到账提醒
- 大促期间提前蹲守

### 3.3 优惠券使用
#### 3.3.1 使用步骤
1. 领取优惠券后存入"我的优惠券"
2. 下单时系统自动匹配可用优惠券
3. 选择要使用的优惠券
4. 确认抵扣金额
5. 提交订单

#### 3.3.2 使用规则
- 单笔订单限用一张优惠券
- 优惠券不可叠加使用（一张订单只能用一张）
- 优惠券不找零，不兑现
- 优惠券抵扣部分不开发票
- 优惠券过期自动失效

### 3.4 优惠券有效期
- 一般优惠券有效期7-30天
- 大促券有效期较短（1-3天）
- 补偿券有效期较长（30-90天）
- 到期前3天发送提醒

## 四、秒杀活动

### 4.1 秒杀规则
- 限时特价商品，数量有限
- 秒杀时间内下单享受秒杀价
- 每人限购数量（一般1-3件）
- 秒杀商品不支持7天无理由退货（质量问题除外）

### 4.2 秒杀参与
1. 关注秒杀活动时间
2. 提前加入购物车
3. 活动开始后立即下单
4. 10分钟内完成支付
5. 超时未支付订单取消，释放库存

### 4.3 秒杀注意事项
- 秒杀商品不与其他优惠叠加
- 秒杀商品不支持价保
- 秒杀订单优先发货
- 如遇系统问题，以最终支付结果为准

## 五、团购活动

### 5.1 团购规则
- 多人成团享受团购价
- 成团人数：2-10人不等
- 成团时间：24小时内
- 未成团自动退款

### 5.2 团购参与
1. 选择团购商品
2. 选择"开团"或"参团"
3. 分享团购链接给好友
4. 凑齐人数后成团
5. 成团后发货

## 六、优惠叠加规则

### 6.1 可叠加组合
| 优惠类型 | 是否可叠加 |
|---------|-----------|
| 会员折扣+优惠券 | 可以 |
| 会员折扣+满减 | 可以 |
| 优惠券+满减 | 可以 |
| 优惠券+秒杀 | 不可以 |
| 满减+秒杀 | 不可以 |
| 团购+其他 | 不可以 |

### 6.2 优惠计算顺序
1. 商品原价
2. 会员折扣
3. 优惠券
4. 满减
5. 积分抵扣
6. 最终实付金额

### 6.3 优惠上限
- 单笔订单最高优惠不超过商品金额的50%
- 积分抵扣最高不超过订单金额的30%
- 优惠券和满减叠加后不超过商品金额的40%

## 七、价格保护

### 7.1 价保规则
- 价保期：签收后7天内
- 适用：商品降价（非活动价）
- 补差：退还差价至原支付账户

### 7.2 不适用价保
- 秒杀、团购等活动商品
- 使用优惠券后的价格
- 跨店满减活动
- 赠品活动
- 预售商品

## 八、活动常见问题

### 8.1 满减问题
**问：满减可以和优惠券一起用吗？**
答：可以。满减和优惠券可以叠加使用。

**问：满减是按商品原价还是实付价计算？**
答：按优惠券抵扣后的实付金额计算。

**问：跨店满减怎么计算？**
答：参与活动的店铺订单合并计算满减金额。

### 8.2 优惠券问题
**问：一个订单可以用几张优惠券？**
答：一个订单只能使用一张优惠券。

**问：优惠券过期了能补吗？**
答：一般不补。特殊情况（如系统问题）可联系客服处理。

**问：退款后优惠券退回吗？**
答：未使用的优惠券退回，已使用的优惠券不退回。

**问：优惠券可以转让吗？**
答：优惠券仅限本人使用，不可转让。

### 8.3 秒杀问题
**问：秒杀没抢到怎么办？**
答：秒杀库存有限，没抢到可关注下次活动。

**问：秒杀商品可以退货吗？**
答：质量问题可以退货，不支持7天无理由退货。

## 十、优惠叠加计算示例

### 10.1 示例一
商品价格：599元
会员等级：金卡（95折）
优惠券：满199减30
满减：满399减80

计算：
1. 会员折扣：599 × 0.95 = 569.05元
2. 优惠券：569.05 - 30 = 539.05元
3. 满减：539.05 - 80 = 459.05元
实付：459.05元

### 10.2 示例二
商品价格：1299元
会员等级：铂金（92折）
优惠券：满799减100
满减：满999减200
积分抵扣：2000积分=20元

计算：
1. 会员折扣：1299 × 0.92 = 1195.08元
2. 优惠券：1195.08 - 100 = 1095.08元
3. 满减：1095.08 - 200 = 895.08元
4. 积分抵扣：895.08 - 20 = 875.08元
实付：875.08元
