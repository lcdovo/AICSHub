# 订单查询与物流追踪操作指南

## 一、订单查询概述

### 1.1 查询功能简介
本平台提供便捷的订单查询服务，消费者可随时查看订单状态、物流信息、订单详情等。支持通过App、网页、小程序等多渠道查询。

### 1.2 订单状态说明
| 订单状态 | 说明 | 可执行操作 |
|---------|------|-----------|
| 待付款 | 订单已提交，等待支付 | 立即支付、取消订单 |
| 待发货 | 已付款，等待商家发货 | 提醒发货、申请退款 |
| 已发货 | 商品已发出，运输中 | 查看物流、确认收货 |
| 待收货 | 商品已送达，等待确认 | 确认收货、申请售后 |
| 已完成 | 订单已完成 | 评价、申请售后 |
| 已取消 | 订单已取消 | 重新购买 |

### 1.3 订单号说明
订单号格式：ORD + 年月日 + 4位序号，如 ORD202609061234。订单号是查询订单的重要凭证，请妥善保存。

## 二、订单查询方法

### 2.1 App查询
#### 2.1.1 查询全部订单
1. 打开App，点击"我的"
2. 点击"全部订单"
3. 查看所有订单列表

#### 2.1.2 按状态筛选
在订单列表页可按状态筛选：
- 待付款
- 待发货
- 待收货
- 待评价
- 已完成
- 已取消/退款

#### 2.1.3 搜索订单
通过搜索框输入以下信息快速查找订单：
- 订单号
- 商品名称
- 收货人姓名
- 手机号

### 2.2 网页查询
1. 登录官网www.example.com
2. 点击"我的订单"
3. 查看或搜索订单

### 2.3 小程序查询
1. 打开微信，搜索本平台小程序
2. 进入"我的-我的订单"
3. 查看订单信息

### 2.4 短信查询
系统会在订单状态变更时发送短信通知，短信中包含订单号和简要状态信息。

## 三、订单详情查看

### 3.1 订单基本信息
在订单详情页可查看：
- **订单信息**：订单号、下单时间、订单状态
- **商品信息**：商品名称、规格、数量、单价、小计
- **收货信息**：收货人、手机号、收货地址
- **支付信息**：支付方式、支付时间、交易流水号
- **费用明细**：商品金额、运费、优惠金额、实付金额
- **发票信息**：发票类型、抬头、税号

### 3.2 物流信息
- 承运快递公司
- 快递单号
- 物流轨迹
- 预计送达时间
- 派件员联系方式

### 3.3 操作记录
订单详情页展示完整操作时间线：
- 下单时间
- 付款时间
- 发货时间
- 签收时间
- 评价时间

## 四、物流追踪

### 4.1 查看物流
#### 4.1.1 App查看
1. 进入订单详情
2. 点击"查看物流"
3. 查看完整物流轨迹

#### 4.1.2 快递公司官网查询
复制快递单号，到对应快递公司官网查询：
- 顺丰：www.sf-express.com
- 京东物流：www.jdl.com
- 中通：www.zto.com
- 圆通：www.yto.net.cn
- 韵达：www.yundaex.com

### 4.2 物流状态说明
| 物流状态 | 说明 |
|---------|------|
| 已揽收 | 快递员已取件 |
| 运输中 | 包裹在运输途中 |
| 派送中 | 快递员正在派送 |
| 已签收 | 包裹已签收 |
| 异常 | 出现问题（如地址不详、拒收等） |

### 4.3 预计送达时间
- **一线城市**：1-2天
- **二线城市**：2-3天
- **三四线城市**：3-5天
- **偏远地区**：5-7天

实际送达时间以物流信息为准。

### 4.4 物流异常处理
#### 4.4.1 物流长时间不更新
- 超过24小时未更新：联系客服催促
- 超过48小时未更新：申请物流调查
- 超过72小时未更新：可申请补发或退款

#### 4.4.2 包裹签收但未收到
1. 检查是否为家人/同事代收
2. 查看快递柜或代收点
3. 联系派件员核实
4. 如确认丢失，联系客服处理

#### 4.4.3 包裹损坏
1. 签收前检查包装，如有损坏可拒收
2. 如已签收，拍照留证
3. 联系客服申请售后

## 五、订单修改与取消

### 5.1 修改订单
#### 5.1.1 可修改内容（未付款订单）
- 收货地址
- 发票信息
- 支付方式

#### 5.1.2 修改方法
1. 进入订单详情
2. 点击"修改订单"
3. 修改需要变更的信息
4. 保存修改

### 5.2 取消订单
#### 5.2.1 未付款订单
- 直接点击"取消订单"
- 选择取消原因
- 订单立即取消

#### 5.2.2 已付款未发货订单
- 点击"申请取消"
- 选择取消原因
- 审核通过后退款（1-3个工作日）

#### 5.2.3 已发货订单
- 无法直接取消
- 需拒收后申请退货退款

### 5.3 修改收货地址
- **未发货**：可在订单详情修改
- **已发货**：联系客服修改（可能产生额外运费）

## 七、订单相关常见问题

### 7.1 订单查询问题
**问：找不到订单怎么办？**
答：1）确认登录的账号是否正确；2）尝试用订单号搜索；3）检查是否在其他账号下单；4）联系客服查询。

**问：订单号在哪里查看？**
答：在订单详情页顶部，格式为ORD开头的16位数字。

**问：可以查询多久以前的订单？**
答：平台永久保存订单记录，可查询所有历史订单。

### 7.2 物流问题
**问：物流信息不更新怎么办？**
答：物流信息更新可能有延迟，建议等待24小时后再查看。如长时间未更新，联系客服催促。

**问：显示已签收但没收到货？**
答：可能是家人代收或放在快递柜，请先核实。如确认未收到，联系客服处理。

**问：可以指定快递公司吗？**
答：下单时可备注偏好的快递公司，我们会尽量满足，但不保证一定能指定。

### 7.3 发货问题
**问：什么时候发货？**
答：一般下单后24小时内发货，预售商品以页面说明为准。大促期间可能延迟1-2天。

**问：可以加急发货吗？**
答：联系客服备注加急，我们会优先处理，但不保证具体发货时间。

**问：分批发货是什么意思？**
答：如订单包含多个商品且部分缺货，会分批发货，运费不额外收取。
