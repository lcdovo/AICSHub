# 产品质保与售后服务政策

## 一、质保政策概述

### 1.1 质保承诺
本平台所有商品均提供正规质保服务。我们承诺：自商品签收之日起，在正常使用情况下出现的非人为质量问题，将按照本政策提供免费维修、更换或退款服务。

### 1.2 质保期限
| 商品类别 | 质保期限 | 备注 |
|---------|---------|------|
| 智能手表 | 1年 | 表带等易损件6个月 |
| 无线耳机 | 1年 | 充电盒1年，电池6个月 |
| 机械键盘 | 2年 | 轴体和键帽1年 |
| 显示器 | 3年 | 屏幕面板3年，其他部件1年 |
| 配件类 | 6个月 | 线材、充电器等 |
| 定制商品 | 不提供质保 | 除质量问题外 |

### 1.3 质保范围
#### 1.3.1 质保覆盖
- 商品功能故障
- 制造工艺缺陷
- 元器件损坏（非人为因素）

#### 1.3.2 质保不覆盖
- 人为损坏（摔落、挤压、进水等）
- 私自拆解或改装
- 未按说明书操作导致的损坏
- 不可抗力造成的损坏
- 正常磨损（如外壳划痕、电池自然衰减）
- 非本平台授权维修造成的损坏

## 二、质保服务申请

### 2.1 申请流程
1. **提交申请**：在订单详情页点击"申请售后"，选择"维修"或"换货"
2. **描述问题**：详细描述故障现象，上传照片或视频
3. **平台审核**：客服在24小时内响应，48小时内完成审核
4. **寄送商品**：审核通过后，按指引将商品寄至指定售后中心
5. **检测维修**：售后中心收到商品后3个工作日内完成检测
6. **返回商品**：维修完成后寄回，运费由平台承担

### 2.2 所需材料
- 订单号或购买凭证
- 商品照片（含序列号）
- 故障描述和相关证明材料

### 2.3 维修时限
- **一般故障**：收到商品后3-5个工作日完成
- **复杂故障**：5-10个工作日完成
- **需返厂维修**：10-20个工作日完成
- **特殊零件**：视零件供应情况而定，最长不超过30个工作日

## 三、维修服务

### 3.1 免费维修
在质保期内，符合质保范围的故障提供免费维修服务，包括：
- 免费检测
- 免费更换故障零部件
- 免费人工服务费
- 免费物流费（寄回运费）

### 3.2 有偿维修
超出质保期或不属于质保范围的故障，提供有偿维修服务：
#### 3.2.1 维修费用构成
- **检测费**：50元（如选择维修则免检测费）
- **零件费**：按实际更换零件成本收取
- **人工费**：根据故障复杂度收取，50-300元不等
- **物流费**：消费者承担寄往售后的运费，平台承担寄回运费

#### 3.2.2 报价流程
1. 售后中心检测后出具维修报价单
2. 消费者确认是否维修
3. 如放弃维修，需支付检测费和物流费
4. 如确认维修，支付费用后开始维修

#### 3.2.3 维修质保
维修更换的零部件享受90天质保（自维修完成之日起计算）。如90天内同一故障再次出现，免费返修。

### 3.3 无法维修的情况
以下情况可能无法维修：
- 商品已停产，无配件供应
- 损坏严重，维修成本超过商品价值
- 私自拆解导致无法修复
- 无法确定故障原因

无法维修时，可协商更换同型号商品或折价退款。

## 四、换货服务

### 4.1 换货条件
符合以下条件之一，可申请换货：
1. 商品存在质量问题，且在换货期限内
2. 商品无法维修或维修周期过长
3. 经协商双方同意换货

### 4.2 换货流程
1. 消费者申请换货
2. 平台审核确认
3. 消费者寄回原商品
4. 平台验收（3个工作日）
5. 发出新商品（验收通过后1-2个工作日）

### 4.3 换货规则
- 仅支持更换同型号、同规格商品
- 如原商品已停产，可更换升级型号（需补差价）
- 换货后的商品质保期重新计算

## 五、延保服务

### 5.1 延保产品
本平台提供延保服务，消费者可在购买商品时或质保期内购买：
- **延长1年**：商品价格的8%
- **延长2年**：商品价格的15%
- **延长3年**：商品价格的20%

### 5.2 延保服务内容
- 在原质保基础上延长质保期限
- 延保期内享受与原质保相同的服务
- 延保期内维修免人工费

### 5.3 延保不覆盖
- 人为损坏
- 不可抗力
- 私自改装
- 正常磨损

## 八、常见问题

**问：质保期从什么时候开始计算？**
答：从商品签收之日起计算，以物流签收时间为准。

**问：没有发票还能享受质保吗？**
答：可以。平台可通过订单记录查询购买信息，无需提供发票。

**问：屏幕有几个坏点可以换货？**
答：根据行业标准，显示器屏幕坏点超过3个（含）可申请换货，3个以内属于正常范围。

**问：电池续航下降可以质保吗？**
答：电池属于消耗品，质保期为6个月。质保期内经检测电池容量衰减超过30%可免费更换。

**问：商品过了质保期还能维修吗？**
答：可以提供有偿维修服务，具体费用请咨询客服。
