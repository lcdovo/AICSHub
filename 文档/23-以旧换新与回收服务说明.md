# 以旧换新与回收服务说明

## 一、服务概述

### 1.1 服务介绍
本平台提供电子产品以旧换新和回收服务，帮助用户处理闲置电子产品，同时享受新品购买优惠。回收的电子产品将进行专业检测和环保处理，部分可正常使用的设备将进行翻新再销售。

### 1.2 服务理念
- **环保**：减少电子废弃物，促进资源循环利用
- **便捷**：在线估价，上门取件，足不出户完成回收
- **透明**：检测标准公开透明，价格合理
- **安全**：数据彻底清除，保护用户隐私

## 二、支持回收的产品

### 2.1 本平台产品
- 智能手表
- 无线蓝牙耳机
- 机械键盘
- 显示器
- 其他本平台销售的电子产品

### 2.2 其他品牌产品
部分品类支持回收其他品牌：
- 智能手表（各品牌）
- 无线耳机（各品牌）
- 机械键盘（各品牌）
- 显示器（各品牌）
- 手机（主流品牌）
- 笔记本电脑（主流品牌）
- 平板电脑（主流品牌）

### 2.3 不支持回收的产品
- 损坏严重无法开机的产品
- 进水、摔坏的产品
- 非电子产品
- 违法违规产品
- 来源不明的产品

## 三、估价流程

### 3.1 在线估价
1. 选择产品品类和型号
2. 填写产品状况（外观、功能、配件等）
3. 上传产品照片
4. 系统自动估价
5. 显示预估价

### 3.2 估价因素
| 因素 | 权重 | 说明 |
|------|------|------|
| 产品型号 | 30% | 型号越新，价格越高 |
| 外观成色 | 25% | 有无划痕、磕碰 |
| 功能状况 | 25% | 功能是否正常 |
| 配件齐全 | 10% | 原装配件是否齐全 |
| 购买时间 | 10% | 购买时间越近越好 |

### 3.3 成色标准
#### 3.3.1 9成新及以上
- 外观无明显划痕和磕碰
- 功能完全正常
- 配件齐全
- 包装完好

#### 3.3.2 7-8成新
- 外观有轻微使用痕迹
- 功能完全正常
- 配件可能不全
- 包装可能缺失

#### 3.3.3 5-6成新
- 外观有明显划痕或磕碰
- 功能基本正常
- 配件可能缺失
- 不影响正常使用

#### 3.3.4 5成新以下
- 外观有严重磨损
- 功能可能有小问题
- 按残值估价

### 3.4 最终价格
- 在线估价为预估价
- 最终价格以实物检测为准
- 如实际状况与描述不符，会重新估价
- 用户可选择接受或取消

## 四、回收流程

### 4.1 提交回收申请
1. 在App/官网进入"以旧换新"页面
2. 选择产品并填写状况
3. 确认预估价
4. 提交回收申请

### 4.2 上门取件
- 审核通过后安排顺丰上门取件
- 运费由平台承担
- 取件时确认产品信息
- 提供取件凭证

### 4.3 专业检测
- 收到产品后24小时内完成检测
- 检测项目：外观、功能、配件、真伪
- 检测过程全程录像
- 出具检测报告

### 4.4 确认交易
- 检测完成后通知用户最终价格
- 用户确认接受价格
- 款项24小时内到账
- 如不接受，产品免费寄回

## 五、以旧换新

### 5.1 换新流程
1. 选择要回收的旧产品
2. 获得估价
3. 选择要购买的新产品
4. 旧产品估价抵扣新品价格
5. 支付差价
6. 寄出旧产品，收到新产品

### 5.2 换新优惠
- 以旧换新享额外补贴
- 补贴金额：新产品价格的5%-15%
- 补贴可与其他优惠叠加
- 部分新品享专属换新价

### 5.3 换新注意事项
- 旧产品需在7天内寄出
- 新品先发货，旧产品后回收
- 如旧产品检测不符，需补差价
- 换新订单不支持取消

## 六、数据安全

### 6.1 数据清除
回收的产品将进行数据清除：
- 恢复出厂设置
- 格式化存储
- 多次覆写数据
- 不可恢复的数据擦除

### 6.2 用户责任
建议用户在寄出前自行清除数据：
- 解绑账号
- 退出登录
- 恢复出厂设置
- 删除个人文件

### 6.3 隐私保护
- 检测过程不查看用户数据
- 数据清除由专人负责
- 签署保密协议
- 如有数据泄露，承担相应责任

## 七、环保处理

### 7.1 可再利用产品
- 检测合格的产品进行翻新
- 更换损坏部件
- 重新包装销售
- 提供翻新质保

### 7.2 不可再利用产品
- 拆解零部件分类回收
- 贵金属提取
- 塑料金属分类处理
- 交由有资质的环保企业处理

### 7.3 环保认证
- 回收处理符合环保法规
- 不随意丢弃电子废弃物
- 优先资源循环利用
- 定期接受环保检查

## 九、常见问题

**问：回收价格怎么定的？**
答：根据产品型号、成色、功能状况、配件齐全程度等综合评估。

**问：回收后多久能收到钱？**
答：检测通过并确认价格后，24小时内打款。

**问：对回收价格不满意怎么办？**
答：可以拒绝，产品免费寄回，不产生任何费用。

**问：回收的数据安全吗？**
答：我们会进行专业数据清除，建议用户寄出前自行恢复出厂设置。

**问：可以回收其他品牌的产品吗？**
答：部分品类支持其他品牌，具体以估价页面为准。

**问：以旧换新怎么操作？**
答：选择旧产品估价→选择新品→旧产品抵扣→支付差价→完成。

**问：回收需要运费吗？**
答：不需要，平台承担来回运费。
