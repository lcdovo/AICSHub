# 企业采购与批量定制服务指南

## 一、企业采购服务概述

### 1.1 服务定位
本平台为企业客户提供一站式采购解决方案，涵盖办公设备采购、员工福利发放、商务礼品定制、批量采购优惠等服务。目前已服务超过5000家企业客户，包括知名互联网公司、金融机构、政府部门等。

### 1.2 服务优势
- **专属价格**：批量采购享受阶梯折扣
- **专属客服**：1对1客户经理全程对接
- **灵活结算**：支持月结、预付等多种结算方式
- **统一开票**：合并开具增值税专用发票
- **配送服务**：支持分批次、多地址配送

## 二、企业采购流程

### 2.1 注册企业账户
1. 进入企业采购页面
2. 填写企业信息（名称、税号、联系人等）
3. 上传营业执照
4. 等待审核（1-2个工作日）
5. 审核通过后开通企业账户

### 2.2 选品与询价
#### 2.2.1 选品方式
- 自主选品：在企业采购专区浏览商品
- 推荐选品：根据需求由客户经理推荐
- 定制选品：特殊需求可联系客户经理

#### 2.2.2 询价流程
1. 提交采购需求（商品、数量、预算）
2. 客户经理1个工作日内报价
3. 确认价格和服务条款
4. 签订采购合同

### 2.3 下单与结算
#### 2.3.1 下单方式
- 线上批量下单：支持Excel导入
- 客户经理协助下单
- API对接（大型企业）

#### 2.3.2 结算方式
- **预付结算**：付款后发货，享额外折扣
- **月结结算**：信用良好企业可申请30天账期
- **分期付款**：大额订单可协商分期

### 2.4 配送与验收
- 支持统一配送至指定地址
- 支持分批次配送
- 支持多地址配送（员工福利）
- 到货后3个工作日内验收

## 十、常见问题

**问：企业采购需要什么资质？**
答：需要提供营业执照和一般纳税人资格证明（如需专票）。

**问：最少采购多少可以享受批发价？**
答：10件起可享受批量折扣，具体以商品为准。

**问：可以开发票吗？**
答：可以，支持增值税普通发票和专用发票。

**问：可以分多次发货吗？**
答：可以，支持分批配送和多地址配送。

**问：定制LOGO需要多少费用？**
答：根据工艺和数量，10-50元/件不等，批量可减免。

**问：如何申请企业账户？**
答：在企业采购页面提交企业信息，1-2个工作日审核通过。
