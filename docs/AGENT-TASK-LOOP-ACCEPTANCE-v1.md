## 实施中发现并处理的问题

- 预览条件可能在下一次确认时失效：原始条件已绑定退款动作，并在提交事务重新核验。
- 新调度分支曾只检查原因非空，与原六字补槽标准不一致：改为复用共同策略，新增短原因回归。
- 调度任务被重放时不能重新写同一组步骤：原API通过持久Run直接返回结果，步骤还有任务/Run/序号唯一约束。
- 回答流水线同步拆分后，旧回执恢复的局部适配器缺少工具证据接口：补齐固定回执校验适配，恢复不调用模型、不重做写。
- 同步运行的其他源码修改曾导致部分全绿结果被起止指纹检查拒绝：保留原记录，不把漂移结果当成冻结通过。
