## 主要发现

1. 21条无答案组题实际上允许基于已知条款给出否定、限制或风险提醒，例如隐私模式不删除录像、恢复出厂不取消第三方订阅。现有评分器对kind=unanswerable强制not accepted，可能误罚被审查接受的正确否定回答；这不是把unsupported一律改成supported，必须区分用户命题与实际回答的支持度。
2. 13条已标partial的题缺少相关证据/已知条件/待补信息，需记录“先说明已知限制再补问”的正确行为，不能只靠拒绝计分。
3. 2条权限题与1条模拟退款题属于授权/回执边界，不应仅按RAG无证据处理；3条安全提醒/补问正例也应独立计响应行为。
4. 4条数字反例仅提高区间下界，仍可能是在合法范围内给保守建议；应明确是否在陈述完整规格，或用确实越界的能力保证构造反例，避免数字不相同就误拒。
5. 1条窗帘题问防夹，但原证据主要谈承重保护，范围不同。标签机2条关联事实分别限制12毫米介质、15毫米见方二维码，未说明二维码能力是否根本不提供，需澄清可行性。
6. 1条显示器240Hz题没有指定分辨率，不能仅由4K60Hz外推所有分辨率均不支持240Hz。
