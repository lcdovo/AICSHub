## 实现

- 每实例RLock保护首次客户端创建，避免并发创建多个池。已识别本地端点trust_env=false；外部端点保持true。没有读取/输出代理凭据或改宿主代理。
- 借用池时增加引用，close拒绝创建新池，最后一个在途HTTP返回后关闭；多次close不重复关闭。只管理HTTP连接，不保证取消服务端模型。
- 本地客户端在准入通过后创建，BUSY不会先构造池。初始化/等锁消耗原阶段截止，构建后重新计算HTTP剩余时间；JSON/向量校验后复核截止，迟到结果不缓存。
- 外部请求粒度、重试配置和文本缓存保持；引用管理限每个APIEmbedding实例，不宣称解决管理器全局单例/后端切换的所有竞态或长期文本缓存问题。
- 保留本地5秒阶段/10秒整轮、active1/waiters2/500ms准入及20完整候选。同步构造/JSON不能硬中断，socket配置不是严格墙钟取消。
