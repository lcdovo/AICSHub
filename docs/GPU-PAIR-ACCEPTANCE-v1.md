## 切换结论

业务切换暂不执行。当前单卡双模型能常驻不代表满足时延/并发目标；在本负载上串行已有4%超时，并发10为43%超时，原重排P95≤2秒未通过。观察更符合延迟/排队瓶颈而不是已证实的OOM，根因还需服务级时序/设备负载复核。下个切片建议先实现/验证双模型共享有界调度、背压与超载明确拒绝，避免把并发10直接扔入Infinity/Ollama队列；不降低候选数/长度/原2秒目标，不删除失败或反复刷结果。

原CPU业务服务/环境配置和业务索引保留；候选容器与新增隔离collection保持原运行/数据状态，没有删除资源。M4实体质量、595人工复核、真实聊天/Judge质量、长期性能/全链路Run、索引兼容和回滚仍单独验收，M5保持INCOMPLETE。
